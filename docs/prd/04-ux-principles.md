# 04 — UX Principles

PRD section: §7. These are copy and interaction constraints, not suggestions.

1. Use **child-friendly language**, not threat-oriented language.
2. Avoid **"TIME'S UP!"** as the primary emotional framing.
3. Give the child **advance notice** and a **concrete next activity**.
4. Minimize interaction complexity during the **final five minutes**.
5. Parent controls should be **clear and deliberate**.
6. The child experience must **not** expose technical settings or authorization details.
7. The enforcement mechanism must be **real** — a UI-only countdown is not a complete MVP.

## Copy review checklist
Before shipping any child-facing string, check:

- [ ] Would a 5-year-old understand it?
- [ ] Does it name what happens **next**, not only what is ending?
- [ ] Is it free of blame, threat, and exclamation-heavy urgency?
- [ ] Does it avoid technical terms (shield, authorization, threshold, entitlement, extension)?
